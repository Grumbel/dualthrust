# dualthrust

A small CRT-green **cave lander** with two engines and nothing else. Each trigger drives one
engine: push both to climb, favour one side to rotate and slide sideways. Fly through a
2D cave and set the ship down on a landing pad.

![dualthrust: lifting off from a landing pad](docs/screenshot.png)

## Playing

The ship has no steering, just a left and a right engine mounted a little apart. Equal thrust
lifts you straight up, uneven thrust spins you, and a tilted ship pushes sideways. Gravity never
stops pulling, so every correction costs altitude.

**Landing.** The ship is a real rigid body (Box2D): it rests on two sprung landing legs, so you can set down
anywhere the ground allows, on a pad or on a slope. Touch down slowly and the legs soak it up with a little
bounce; the ship counts as *landed* once it is upright, almost still and your thrust is off. On sloped ground it
tilts with the slope and, past a steep enough angle, slides, as the legs' friction gives out. Pads are flat and
grippy, so they are the safe spot. The HUD (top right) shows `PAD`, `SPEED` and `ATT` hints as you approach
(gentle means under 55 px/s down, 40 px/s sideways and about 13° of tilt).

Hard impacts destroy the ship: hull or engine bells above about 120 px/s into the rock, the feet above about
260 px/s. Anything slower is a bounce. After a landing, just throttle up to lift off again. After a crash,
**Enter** (or **A/B** on a gamepad) respawns you on a random pad; the wreck tumbles on until then. The cave is
never regenerated by a crash.

**Landing legs** retract on a button press (**Space**, or **X** on a gamepad), for tight tunnels and for sitting
on the hull; press again to extend them.

**Rope, hook and cargo.** Every ship carries a winch under the belly. **Q** / **D-pad left** deploys the cable all the way out,
**E** / **D-pad right** retracts it all the way in (no stops in between); the hook hangs from a chain that sags when slack. Fly the hook up to one of the
twelve crates scattered through the cave (cyan on the minimap) and press **R** (or **A** on a gamepad) to grab it; it
then dangles from the hook like a pendulum: the load swings (calmed by drag and friction in the pivot, and it does not
snag the ship), and heavy loads pull the ship down. The cable pulls at the ship's centre of mass, so a swinging crate
cannot spin the ship by itself. Press again to
let go. A crate you lifted and then set down on a landing pad counts as delivered. There are five sizes, from a light
parcel to a heavy container, and the winch reels loaded cables in more slowly. Crates and hook collide with the rock, not
the cable itself.

**Statistics** (Statistics in the title and pause menus): flight and parked time, distance, landings (and how many
on pads), hard hits, crashes, caves visited, crates picked up and delivered. They are kept forever in
`$XDG_STATE_HOME/dualthrust/stats` (default `~/.local/state/dualthrust/stats`).

The cave is a bounded 24000 × 4800 px map with rock on all sides. The minimap at the bottom is a zoomed-in map of the stretch around you (one pixel per 16 world px, about 6400 × 1600
px) that scrolls with the ship and stops at the map edges. It shows the landing pads (yellow), the crates (cyan), your
ship (blinking) and a box for what the main view shows.

### Ships

Eighteen presets, switched in Options, with **S**, or with **Select**. Heavier and wider ships are
steadier but slower to turn.

| Preset | Notes |
|--------|-------|
| Narrow, Medium, Wide, Barge, Long | Engines at the bottom |
| Topdog, Canopy | Engines mounted on top; they still push the ship up |
| Dart, Gnat | Small and quick; Dart is the fastest, Gnat the lightest |
| Hauler, Orca | Heavy, with fuel tanks: the best for towing crates |
| Spire, Moth | Tall and narrow, wide and light |

| Frigate | Big, four thrusters: mains on the triggers, two **side thrusters on the sticks** to strafe without tilting |
| Atlas | Big, mains on the triggers, two **top boosters on the sticks** that push the ship *down*: brake, descend, steer |
| Dragonfly | Mid-size, mains on the triggers, two **crossed 35° thrusters on the sticks**: together they lift, alone they strafe and turn |
| Colossus | The biggest: outboard mains on the triggers, **inboard engines on the sticks** for fine attitude control |

The classic ships have two engines and fold the sticks into them. The four-thruster ships keep all four apart:
left trigger, right trigger, left stick up and right stick up (the HUD shows four bars, `L R LS RS`). On the keyboard the
extra two are **W** / **Up arrow** and **Down arrow** / **Right Alt**. Swap Engines mirrors both pairs.

Ships differ in detail too: fins, fuel tanks beside the cabin (they collide), a glass canopy, a radar dish, hazard
stripes, each with hydraulic landing struts and a winch under the belly.

## Controls

| Input | Action |
|-------|--------|
| Triggers, L1/R1, or stick up (left/right) | Left / right engine (on the big four-thruster ships the sticks are their own two thrusters) |
| Keyboard **W** / **Up**, **Down** / **Right Alt** | The two extra thrusters of the big ships |
| Keyboard **Left Ctrl** / **Right Ctrl** (or **A** / **D**, arrows) | Left / right engine, full thrust |
| Keyboard **Left Shift** / **Right Shift** | Left / right engine, half thrust |
| **Start** / **Escape** | Pause menu (Escape also goes back one page; from the title it quits) |
| D-pad or arrows, **A** / Enter | Menus: move, change values (left/right), select |
| **Space** (keyboard), **X** (gamepad) | Retract / extend the landing legs |
| **Q** / **E**, **D-pad** left / right | Deploy / retract the hook cable (one press) |
| **R** (keyboard), **A** (gamepad) | Hook grabs the crate in reach / lets go (on the gamepad **A** respawns after a crash) |
| **Enter** (keyboard), **A**/**B** (gamepad) | Respawn after a crash |
| **Y** or **G** | New cave |
| **Tab**, mouse wheel, or D-pad up/down | Zoom: Near / Medium / Far |
| **S** or **Select** | Next ship |
| **X** | Swap left/right engines |
| **F** or **Alt+Enter** | Fullscreen |
| **M** | Sound on/off |

On-screen hints follow the device you used last: they name keyboard keys or gamepad buttons accordingly.

**Menus.** The game opens on a title screen (Start, Options, Statistics, Quit). Pausing shows Resume, New Cave, Options,
Statistics, Main Menu and Quit. **Options** has Ship, Zoom, Swap Engines, Music and Effects volume (sliders), CRT Effect
(scanlines and vignette on or off) and Fullscreen; change a value with left/right, or Enter/A to step it forward.
Everything is remembered between runs.

**Zoom** is independent of the screen resolution: Near shows 480 world pixels of height, Medium 720 and Far 1080,
whatever the window or display size. The first start picks Near on small screens such as the R36S's and Medium
elsewhere; after that your choice is remembered.

## Sound

Everything is synthesised at runtime, so there are no audio files: engine rumble (panned left and
right), landing, bounce and crash effects, short beeps for your own actions (hook out and in, grab, release, nothing in
reach, crate delivered, legs), and a slow generative ambient loop. Toggle with **M** or
the menu; start muted with `--mute`. If no audio device is available the game runs silently.

## Build and run

Requires SDL2, CMake and a C++17 compiler. With Nix:

```sh
nix develop
dualthrust-configure && dualthrust-build && dualthrust-run
# or simply
nix run
```

## Command line

```
dualthrust [options]
  -f, --fullscreen     start fullscreen
  -w, --window WxH     window size (default 1280x720)
  -s, --ship N         ship preset 0..6
  -z, --zoom LEVEL     near, medium or far
  --renderer MODE      auto (GLES2, else SDL), gles2 or sdl
  -S, --seed N         cave seed (same seed, same cave)
  -x, --swap-engines   swap left/right
  -m, --mute           start with sound off
  --config-dir PATH    use another config directory
```

`--play`, `--screen title|pause|options`, `--thrust L,R`, `--frames N` and `--screenshot FILE` exist for automated testing;
see `dualthrust --help`. A man page (`man dualthrust`) is installed with the game.

## Config

Fullscreen, ship, engine swap and sound are saved to `$XDG_CONFIG_HOME/dualthrust/config`
(default `~/.config/dualthrust/config`).

## In the browser (WebAssembly)

```sh
nix build .#dualthrust-wasm   # the site: index.html, dualthrust.{html,js,wasm} in result/
nix run .#dualthrust-wasm     # serve it on 127.0.0.1 and open a browser
```

The whole game runs in a web page; put `result/` on any static web server. Ship, sound and engine-swap
settings are kept in the browser's storage. Keyboard and gamepads work; browsers start audio only after the
first key press or click. See [AGENTS.md](AGENTS.md) for the build details.

## R36S handheld (ArkOS / PortMaster)

A native aarch64 build for the R36S runs at 60 fps on the 640×480 panel:

```sh
nix build .#dualthrust-r36s-portmaster-zip   # PortMaster autoinstall zip
```

Copy `Dualthrust.sh` and `dualthrust/` to `/roms/ports/`, or drop the zip into PortMaster's
`autoinstall` folder. See [AGENTS.md](AGENTS.md) for the sysroot, build and performance notes.

## Desktop install (Linux)

CMake installs the binary, `.desktop` file, icons, man page and AppStream metainfo.
